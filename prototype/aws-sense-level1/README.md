# AWS SENSE Level I Passport Lab

Standalone prototype for testing the AWS SENSE Level I tracking model before integrating anything into LTG.

## Included
- Student roster
- SENSE Passport dashboard
- Knowledge exam tracking with up to 3 attempts
- Safety threshold 100%; other Level I knowledge exams 75%
- Skill status: Not Started -> Introduced -> Practicing -> Competent -> Verified
- Performance qualification records
- Partial/full readiness indicators
- SENSE admin fields
- Browser-local persistence
- JSON export/import

## Important
This is a prototype, not an AWS reporting system and not an LTG production component. It intentionally does not reproduce AWS standards, SWPS documents, or test drawings.

## Run
Open `index.html` directly in a modern browser. No install or backend is required.
