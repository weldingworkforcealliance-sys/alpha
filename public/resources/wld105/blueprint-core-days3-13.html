WLD 105 — Blueprint Core Support, Days 3–13

Use with the 20-minute welding-math block. Blueprint instruction/assessment occupies the remaining classroom block. Drawings below are vector so zoom remains readable.

Day 3 — Introduction to Welding Drawings: From Print to Part

Students should be able to: explain why a drawing controls fabrication; identify title block, material, quantity, revision, general tolerance, notes, and basic views; explain why work should not begin from appearance alone.

Day 4 — Views, Dimensions, Tolerances + Weld-Symbol Anatomy

Students should be able to: transfer a feature between aligned views; read a basic dimension and tolerance; identify reference line, arrow, tail, weld symbol, arrow side and other side; distinguish shown information from assumptions.

Day 10 — Multi-View Weldment Drawings + Print Interpretation

Read views, notes, dimensions, tolerances, features and weld information together. Student evidence: identify what gets made, material, controlling dimensions, required features and inspection points.

Day 11 — Print-to-Project Workflow + Cut Lists

A usable cut list includes quantity, material, dimensions, units, features/angles, notes, and a QC checkpoint. Every line must trace back to the controlling print.

Day 12 — Blueprint / Symbol Review + Practice Exam

Review sequence: controlling source → title block/notes → views → dimensions/tolerances → symbol side/callout → cut list/QC. Use results to identify the final reteach target before the formal exam.

Day 13 — Blueprint & Symbol Exam

Formal assessment day. Students demonstrate individual blueprint-reading and weld-symbol competency. The connected exam records a numeric score for the course grade. No public answer review while an exam session is active.
