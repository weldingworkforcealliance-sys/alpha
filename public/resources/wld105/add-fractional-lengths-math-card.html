WLD 105 Welding Math — Add Fractional Lengths

Goal: Add fractional and mixed-number lengths using common denominators, then simplify the final measurement.

Book connection: Unit 7 — Addition of Common Fractions

1. Common Denominator Visual

2. Mixed-Number Method

Example A

2 3/8 + 1 5/8

Whole numbers: 2 + 1 = 3

Fractions: 3/8 + 5/8 = 8/8 = 1

Answer: 4 in

Example B

1 3/4 + 2 5/16

Rewrite 3/4 as 12/16.

12/16 + 5/16 = 17/16 = 1 1/16

1 + 2 + 1 1/16 = 4 1/16 in

3. Cut-List Example

3 7/16 in + 2 5/16 in

7/16 + 5/16 = 12/16 = 3/4.

3 + 2 = 5.

Final total = 5 3/4 in

Shop rule: carry units through the problem and simplify the final fraction. Do not add denominators.
