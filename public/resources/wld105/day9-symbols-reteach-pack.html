2. Welding-Symbol Anatomy

Read in this order

  1. Locate the joint/member identified by the arrow.
  2. Determine arrow side versus other side.
  3. Identify weld type.
  4. Read size.
  5. Read length / pitch when present.
  6. Check supplementary symbols.
  7. Read the tail or referenced note.
  8. State the requirement in plain language.

Evidence rule

A correct interpretation must be tied to visible print evidence. Require students to point to the symbol element, dimension, note, or joint location that supports the answer.

No evidence, no acceptance.

3. Supplementary / Complete Symbol Checks

ElementStudent should verify
Arrow side / other sidePlacement relative to the reference line and the actual joint identified by the arrow.
SizeSpecified size and drawing units.
Length / pitchRequired weld length and intermittent spacing when shown.
All-aroundWhether the supplementary symbol applies around the applicable joint.
Field weldWhether the print identifies field rather than shop welding.
Contour / finishSpecified contour and finish method from the authorized reference.
Tail notesActual process, procedure, specification, or reference note. Never guess.

4. Joint-to-Print Evidence

JointEvidence promptCommon trap
ButtPoint to the members meeting in approximately the same plane and any edge preparation shown.Assuming every butt joint is automatically a groove weld.
LapPoint to the overlap and the exact edge/joint addressed by the arrow.Assuming both exposed edges receive the same weld.
T-jointPoint to the member intersection and identify arrow side / other side.Choosing the visible side instead of reading the symbol.
CornerPoint to the member relationship and read the specified weld.Treating joint type and weld type as the same thing.
Complete exampleState weld type, side, size, length/pitch, supplementary information, and exact joint location.Skipping the tail, all-around/field indicators, or finish requirement.
