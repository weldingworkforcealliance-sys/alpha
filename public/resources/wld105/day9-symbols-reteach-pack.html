2. Supplementary / Complete Welding Symbol Reference

Read the entire symbol before interpreting any one mark. Start with the arrow and reference line, identify arrow-side versus other-side information, then read weld type, size, length/pitch, contour/finish, and supplementary information.

Arrow → joint/member

Tail → process/spec/reference when needed
OTHER SIDE
ARROW SIDE
ElementWhat students should verify
Weld type symbolIdentify the specified weld type from the authorized symbol reference. Do not infer a weld type from joint appearance alone.
Arrow side / other sideFor standard AWS placement, information below the reference line applies to the arrow side; information above applies to the other side.
SizeWhen specified, size information is read at the left side of the weld symbol. Interpret units from the drawing.
Length / pitchWhen specified, length is read to the right of the weld symbol. Intermittent weld pitch follows the applicable length/pitch notation.
All-aroundLook for the all-around supplementary symbol at the arrow/reference-line junction and confirm the print truly requires the weld around the applicable joint.
Field weldLook for the field-weld flag at the arrow/reference-line junction. Confirm the drawing context and job instructions before assuming shop versus field work.
Contour / finishVerify the specified contour and any finish-method designation from the authorized AWS reference. Do not substitute a shop habit for the print requirement.
Tail notesThe tail can carry process, specification, procedure, or other reference information when needed. Read the actual note; never guess what the tail “usually” means.

Complete-symbol reading order

  1. Find the joint/member the arrow identifies.
  2. Read arrow-side / other-side placement.
  3. Identify weld type.
  4. Read size.
  5. Read length / pitch when present.
  6. Read supplementary symbols.
  7. Read tail or referenced note.
  8. State the requirement in plain language and point to the print evidence.

Evidence check

A correct answer is not just a spoken guess. Student should be able to point to the exact symbol element, dimension, note, or joint location that supports the interpretation.

If the evidence cannot be pointed to, recheck the print.

5. Welding Math Lesson Card — Day 8: Add Fractional Lengths

Goal: Add mixed-number lengths using common denominators and simplify.

Book connection: Unit 7 — Addition of Common Fractions

TimeMove
40–42 minStart: Find a common denominator for 3/8 and 1/4.
42–46 minShow: 2 3/8 + 1 5/8 = 3 + 8/8 = 4 in. Check on a tape or number line.
46–52 minPractice: Solve 1 3/4 + 2 5/16 after rewriting fourths as sixteenths.

Do not add denominators. If needed, use tape marks. For students who finish quickly, total three mixed lengths.
