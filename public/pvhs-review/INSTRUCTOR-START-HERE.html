Electronic signoff procedure

The staging signoff screen supports WLD 114 CNC authorization, WLD 120 QC gates and WLD 150 bend-test review. Access requires an authorized reviewer or assigned instructor. Its automated workflow checks passed; signed-in browser verification has not been completed.

  1. Select the section and student. Enter a precise, consistent machine or job/revision scope, then load the history. For example, use the same project-and-drawing-revision text for all three QC gates. Different scope text creates a separate history.
  2. Select the appropriate gate. Read the existing decisions before entering a new one. Confirm evidence belongs to this student and section.
  3. Enter the evidence reference, approved criteria reference and instructor observation. For every criterion, record the requirement, actual observation and an explicit met/not-met result. Use the applicable approved drawing, equipment procedure or test acceptance criteria; this package does not invent technical tolerances.
  4. Choose hold, release or revoke. A release requires all entered criteria to be met. CNC expiration is optional and must be in the future when supplied. Bend-test release additionally requires a passed test result.
  5. Save once and review the returned history. If another instructor has changed it, reload and reassess; do not blindly repeat the save. If saving succeeds but the history cannot refresh, reload before deciding whether another entry is necessary.
  6. Keep technical release separate from the academic grade. A valid signature does not lift the section/calendar hold. Instruction remains unavailable while the section is draft, manually held or undated.

Evidence and grading

Use the daily planner's evidence item and rubric to identify the assessment category. Record the student's artifact ID, course/section, instructional day, drawing or procedure revision, attempt and observed result. Keep the artifact in its approved storage location and enter a usable reference; a reference alone is not proof that the technical criteria were met.

Completed lessons, elapsed time and submitted work do not award a passing grade. Pending machine assessments remain unscored. Once an assessment is actually evaluated, apply its approved rubric and category; preserve prior attempts and correction history. If an attempt is selected for grading, document why. Store individual instructor notes in the section record, not in the shared master lesson.
