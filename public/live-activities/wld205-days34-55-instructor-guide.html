WLD 205 Instructor Support — PVHS Project Extension Days 34–55

Standing project workflow: PRINT/SOURCE → PLAN/MATH → WPS/MATERIAL → WLD-210 PHYSICAL EVIDENCE → INSPECT/RECHECK → RECORD

WLD-205 owns planning, interpretation, math, metallurgy/source reasoning, inspection records, and documentation. WLD-210 owns physical cutting, fit-up, welding, grinding, heating, and fabrication. Never create evidence for work that did not occur.

Day 34 — Project 1A Rectangular Frame: Read + Mark Print

Instructor: issue current frame print/brief. Students mark title/material, overall dimensions, joint locations, reference/datum information, and unresolved requirements.

Use: Project Source Map + Unknowns record. Require source/person for every unresolved item.

Handoff: marked print + exact layout/material-staging requirements to WLD-210.

Day 35 — Project 1B: Cut List + Squareness Math

Instructor: derive member list and quantities from the actual print. Keep kerf/allowance source-controlled.

Math: cut lengths + diagonal/squareness or other print-required comparison.

Gate: member count, length, units, source and squareness math audited before material release.

Day 36 — Project 1C: Metallurgy + WPS/Distortion Plan

Instructor: identify actual base material source and approved WPS/SWPS. Locate only required procedure fields.

Reasoning: material + geometry/restraint → HAZ/weldability/distortion concerns → source-controlled plan.

Evidence request: list measurements/observations WLD-210 must return during fit/tack/weld.

Day 37 — Project 1D: In-Process Evidence + Revision Notes

Instructor: review only actual WLD-210 measurements/photos/records. Compare to print/WPS/project requirement.

Decision: correction | recheck | clarification | approved as-built/revision note.

Rule: factual evidence only; do not backfill or reconstruct work from memory.

Day 38 — Project 1E: Inspection + Closeout

Audit: print, math, WPS/source, measurements, inspection, corrections, as-built notes.

Close: final dimension/tolerance verification + one metallurgy/distortion explanation tied to observed evidence.

Transfer: record one lesson to carry into Project 2.

Day 39 — Project 2A Gusseted Bracket: Print + Joint Detail

Instructor: identify bracket geometry, gusset/joint detail, controlling dimensions and authorized symbol/source references.

Student: build print → WPS/SWPS → material → measurement/inspection source map and flag unresolved requirements.

Handoff: marked joint/layout/QC plan to WLD-210.

Day 40 — Project 2B: Triangle + Angle Math

Instructor: identify triangle/gusset/angle values from the print before formulas.

Student: calculate and convert the results into physical layout/fit checkpoints.

Gate: independent geometry audit before material work continues.

Day 41 — Project 2C: Material Behavior + Distortion Control

Instructor: connect material source, joint restraint, heat/sequence and distortion risk without inventing settings.

Plan: source-controlled sequence + fixture/tack/measurement checkpoints + proof that the control worked.

Day 42 — Project 2D: In-Process Measurement + Corrective Action

Instructor: collect actual WLD-210 values/observations. Compare dimensions/angles/fit to controlling requirement.

Record: original result → deviation → permitted correction → recheck result. Preserve the original measurement.

Day 43 — Project 2E: Closeout + Peer Source Audit

Peer audit: trace one technical decision back through print/WPS/material/calculation/source.

Instructor: close only legitimate documentation gaps. Missing physical work remains missing/pending.

Day 44 — Project 3A Round-Base Support: Print + Circular Features

Instructor: mark diameter/radius/height/circular-feature requirements and physical reference points.

Student: build source map and round-work layout/QC plan.

Handoff: exact circular-feature verification points to WLD-210.

Day 45 — Project 3B: Circle/Cylinder Math + Material Takeoff

Math: circumference, area, cylinder/basic volume, material quantity/weight as applicable. Require linear/square/cubic units correctly.

Source: material weight/density values must come from authorized data, never memory.

Gate: independent source + units + reasonableness check.

Day 46 — Project 3C: Material Selection + HAZ/Distortion Plan

Instructor: identify actual material source and round-base restraint/geometry.

Student: state only supported HAZ/weldability concerns, then build source-controlled distortion/evidence plan.

Day 47 — Project 3D: In-Process Evidence

Compare: actual diameter/roundness/height or specified dimensions to project requirement.

Record: source compliance/deviation → factual basis → correct/recheck/accept decision per governing source.

Day 48 — Project 3E: Closeout + As-Built Record

Audit: print, math, material/WPS, measurements, inspection, correction, as-built notes.

Reflection: one metallurgy/distortion point supported by observed evidence, not a guessed cause.

Day 49 — Project 4A Independent Mini-Fabrication: Project Selection + Source Map

Instructor: approve the project brief before planning. Student builds complete source map and identifies unknowns before any physical work.

Gate: no unresolved critical requirement is filled by assumption.

Day 50 — Project 4B: Math + Material Takeoff

Student: list every required calculation first, then complete dimensions/angles/areas/volumes/weights/tolerances/quantities as applicable.

Audit: method, units, quantities, source values and source-controlled allowances.

Day 51 — Project 4C: Metallurgy + WPS Plan

Student: identify material source + controlling WPS/SWPS, supported HAZ/weldability concerns, distortion plan, and exact WLD-210 evidence to capture.

Rule: record procedure values from the approved source only.

Day 52 — Project 4D: Evidence Audit + Correction

Student: compare actual WLD-210 evidence to print/procedure/tolerance source, write factual corrective action where needed, then update measurement/as-built record after recheck.

Day 53 — Project 4E: Final Technical Packet

Checklist: print | math | material/metallurgy | WPS/source | measurements | inspection | corrective action | as-built evidence.

Instructor conference: trace one source chain end-to-end. Correct only genuine documentation gaps.

Day 54 — Portfolio Audit

Organize: all four project packets.

Audit by WLD-205 CLO: identify actual supported evidence and missing/pending items.

Growth: select one before/after example in print reading, math, source use, metallurgy reasoning or documentation.

Complete documentation only from existing evidence. Do not create evidence for physical work that did not happen.

Day 55 — Final Integrated Technical Review

Presentation chain: print requirement → calculation → metallurgy/WPS decision → actual WLD-210 evidence → final record.

Growth check: new original blueprint/math/metallurgy item, not secure AWS content.

Conference: define exact continuation/retest/makeup plan for unresolved evidence.

Close: portfolio submitted; incomplete evidence remains accurately incomplete.

Project guardrail: acceptance limits, welding procedure values, revision authority, and physical disposition come from the applicable governing source/instructor process. LTG records the decision trail; it does not invent the requirement.
