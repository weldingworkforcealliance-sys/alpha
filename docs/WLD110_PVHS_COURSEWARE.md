# PVHS B/C original courseware in the 55-day plan

Both active PVHS WLD 110 sections use the same 55-day instructor guide. Each guide day now has an instructor-only Safety, SMAW and OFC resource. The dedicated PVHS viewer retains the actual guide-day title, objective and safety focus; its chapter links keep the current PVHS day selected. It uses the existing private image API and the same 77 original purchased slides as the college resources.

`WLD110_PVHS_COURSEWARE_MAP.json` records all 55 day contexts and chapter selections. `sourceDays` is provenance for the existing 23-day slide selections, not a replacement schedule. Equipment/setup resources appear during Days 1–15, E7018/1F during 16–20, 2F and cutting during 21–33, 3F during 34–38, fabrication during 39–43, overhead/closeout during 44–49, and project technique/safety support during the six reserved cube days. The cube remains conditional on approved drawings and instructor approval.

The migration reuses the two existing blank OFC/SMAW packet records and adds the remaining daily links in resource slots 10–12. It preserves other resource records, all college resource URLs, guide curriculum, outcomes, planner-day assignments and timing. No additional image copies, public slide URLs, or authorization changes are introduced.

The existing PVHS schedule remains 120 allocated minutes per day, with its separate work, cleanup and transport accounting. This work does not change that structure or the 23-day Night schedule.

Other pre-existing requirements (course overview, ANSI reference, parameter log, exams and rubrics) remain separate from purchased slide courseware. Thirteen of those records still have no supplied resource URL; they must not be treated as completed by attaching unrelated slide links. The approved cube drawing remains pending.

Validation includes all 165 day/chapter renderings, complete coverage of the existing asset manifest, original image endpoints, chapter/day navigation, cube approval messaging and instructor session failure handling. Live release checks compare curriculum, schedule, outcomes and planner-link fingerprints with the pre-change database baseline and verify all 55 days of both sections.
